# 第一章　总则

## 1.1　制定目的

为提升员工主动学习意愿，解决传统"发礼品"式激励存在的价值感知模糊、边际效用递减等问题，特制定本奖励规则。通过"**连胜递增 + 保底激励**"双轨并行机制，为员工提供持续、透明、可预期的正向反馈。

## 1.2　基本原则

| 原则 | 说明 |
| --- | --- |
| 公平公正 | 排名依据系统自动计算的积分，无人工干预 |
| 即时激励 | {{结算周期}}系统自动结算，奖励自动发放至员工账户 |
| 持续牵引 | 连胜递增机制鼓励员工保持长期稳定表现 |
| 成本可控 | 奖励金额设封顶，预算可预期、可管理 |

# 第二章　统计与排名规则

## 2.1　统计维度

员工{{结算周期}}在{{学习平台名}} APP 内的学习表现，由以下三个维度加权计算：

- **学习分（权重 {{学习分权重}}%）**：本周完成必修课时长、选修课额外学习时长。为防止"刷时长"行为，设置单日学习时长上限。
- **考试分（权重 {{考试分权重}}%）**：本周随堂测验、周考的最高成绩。取当周最高一次考试成绩计入。
- **活跃分（权重 {{活跃分权重}}%）**：发表高质量课程笔记、提出有价值的问题、回答他人问题并被采纳等互动行为。每周设有封顶上限。

## 2.2　统计周期

统计周期为**自然周**：周一 00:00 至 周日 24:00。

- 每周一 00:30，系统自动结算上周所有员工积分及排名。
- 每周一 08:00，系统向所有参评员工推送周报及获奖战报。

## 2.3　排名维度

系统按**{{排名范围}}维度**进行排名，同一范围内的员工根据当周综合得分由高到低排序，得分相同者按"**考试分 ＞ 学习分 ＞ 活跃分**"的优先级规则决定名次。

# 第三章　奖励机制设计

## 3.1　奖励类型总览

| 轨道 | 适用排名 | 奖励形式 | 触发条件 |
| --- | --- | --- | --- |
| A 轨道（连胜递增券） | 第 1 名 | 面额递增的{{奖励类型}} | 连续获得周冠军 |
| B 轨道（保底鼓励券） | 第 2、3 名 | 固定 {{B轨道面额}} 元{{奖励类型}} | 当周排名第 2 或第 3 |

**设计逻辑说明**：

- **A 轨道**负责"制造稀缺感和追逐欲"。连胜递增带来的"怕中断"心理（损失厌恶）比单纯的物质奖励具有更强的驱动力。员工会为了保住高额券而持续投入学习。
- **B 轨道**负责"保底，防止摆烂"。如果只有冠军有奖，第 2 名、第 3 名在赛季中期就可能因为差距过大而放弃竞争。保底券确保前 3 名都有收获，维持整体竞争氛围。

## 3.2　A 轨道：冠军连胜递增券（核心激励）

### 3.2.1　获取条件

员工在当周{{排名范围}}排行榜中排名第 1，且系统判定为连续夺冠状态。

### 3.2.2　面额阶梯表

员工连续获得周冠军的次数，对应不同面额的{{奖励类型}}，具体如下：

| 连续夺冠次数 | 奖励券面额 | 较上一档增幅 |
| --- | --- | --- |
| 第 1 周 | {{起始面额}} 元 | 起始值 |
| 连续第 2 周 | {{起始+增幅}} 元 | +{{增幅}} 元 |
| 连续第 3 周 | {{起始+2*增幅}} 元 | +{{增幅}} 元 |
| 连续第 4 周 | {{起始+3*增幅}} 元 | +{{增幅}} 元 |
| 连续第 {{封顶周}} 周及以上 | {{封顶面额}} 元 | +{{增幅}} 元（封顶） |

**设计意图**：每周递增 {{增幅}} 元，形成清晰的"升级打怪"路径，让员工对下一周的目标有明确预期。设置 {{封顶面额}} 元封顶，避免成本失控，同时保持员工对"满级奖励"的持续向往。

### 3.2.3　连胜计算规则

| 规则项 | 说明 |
| --- | --- |
| 连胜起始 | 员工首次获得周冠军时，连胜周数记为 1，对应 {{起始面额}} 元券 |
| 连胜延续 | 若上一周为冠军且本周再次获得冠军，连胜周数 +1，对应面额按阶梯递增 |
| 连胜封顶 | 连胜周数 ≥ {{封顶周}} 时，统一发放 {{封顶面额}} 元券，不再递增 |
| 连胜中断 | 若某周未获得第 1 名，连胜周数清零，下一次夺冠时从第 1 周重新计算 |

### 3.2.4　断连规则详解

以下任一情况均视为连胜中断：

- 某周排名不是第 1 名（即使仍在前 3 名）；
- 某周未产生积分（未参与任何学习活动）。

**中断后果**：

- 连胜周数重置为 0；
- 下周若重新夺冠，从 {{起始面额}} 元重新累积；
- 中断当周，若排名为第 2 或第 3，可同步享受 B 轨道保底券。

> **示例说明**：
> 员工 A 连续 3 周冠军，第 3 周获得 {{起始+2*增幅}} 元券。
> 第 4 周因考试失误排名第 2，获得 {{B轨道面额}} 元保底券，连胜中断（连胜归零）。
> 第 5 周重返第 1，重新从 {{起始面额}} 元券开始累积（非 {{起始+2*增幅}} 元）。

## 3.3　B 轨道：前三保底鼓励券（防挫败机制）

### 3.3.1　获取条件

员工当周{{排名范围}}排行榜中排名为**第 2 名**或**第 3 名**，系统自动发放，无需额外申请。

### 3.3.2　奖励内容

| 排名 | 奖励券面额 | 说明 |
| --- | --- | --- |
| 第 2 名 | {{B轨道面额}} 元 | 固定额度 |
| 第 3 名 | {{B轨道面额}} 元 | 固定额度 |

### 3.3.3　与连胜记录的交互规则

| 场景 | 对连胜记录的影响 | 对奖励的影响 |
| --- | --- | --- |
| 冠军获得保底券 | 连胜记录归属 A 轨道，与 B 轨道无关 | 仅发 A 轨道券，不发 B 轨道券 |
| 非冠军获得保底券 | 不打断冠军连胜记录（若该员工此前连胜已中断，则不恢复） | 获得 {{B轨道面额}} 元券 |
| 第 2 名 / 第 3 名获得保底券 | 不涉及连胜逻辑 | 获得 {{B轨道面额}} 元券 |

**核心原则**：保底券仅作为"未夺冠但表现优秀"的补偿激励，不参与连胜累积逻辑。连胜记录仅与"是否获得当周第 1 名"有关，与获得保底券无关。

### 3.3.4　设计意图

当员工因微小差距（如 1 分之差）未能夺冠时，{{B轨道面额}} 元保底券起到"情绪兜底"作用，避免产生"努力白费"的挫败感，从而维持其持续参与的动力。

## 3.4　每周奖励发放流程

| 时间节点 | 系统动作 | 触发方式 |
| --- | --- | --- |
| 每周一 00:30 | 结算上周所有员工积分，生成{{排名范围}}排名 | 定时任务自动触发 |
| 每周一 00:35 | 计算每位员工的连胜状态，确定 A 轨道获奖者 | 定时任务自动触发 |
| 每周一 00:40 | 生成 A 轨道券（{{阶梯面额列表}}）并发放至冠军账户 | 定时任务自动触发 |
| 每周一 00:45 | 生成 B 轨道券（{{B轨道面额}} 元）并发放至第 2、3 名账户 | 定时任务自动触发 |
| 每周一 08:00 | 向全体员工推送周报战报（含获奖名单、券面额） | 定时任务自动触发 |
| 员工主动使用 | 在 APP"奖励中心"查看券，选择兑换通道 | 手动操作 |

**异常处理**：若结算日遇法定节假日或系统故障，顺延至下一个工作日执行。中断规则不受顺延影响，按自然周连续计算。

## 4.2　双通道兑换机制

员工在 APP 内查看已获得的券时，系统提供两种兑换通道供员工自行选择：

### 通道 A：福利商城快捷兑换

| 规则项 | 说明 |
| --- | --- |
| 适用场景 | 员工不想额外支付现金，希望直接兑换商品 |
| 兑换方式 | 在 APP"员工福利商城"内，选择指定福利款商品直接兑换 |
| 商品池 | 固定上架 {{SKU数量}} 款精选商品（如 {{示例SKU}} 等） |
| 费用 | 员工无需额外付款，券面额足以覆盖商品成本价 |
| 差额处理 | 若商品成本价低于券面额，差额不退回；若商品成本价高于券面额，不支持兑换（系统自动过滤） |

### 通道 B：全场无门槛抵扣券

| 规则项 | 说明 |
| --- | --- |
| 适用场景 | 员工愿意搭配购买正价商品，享受更高价值 |
| 兑换方式 | 兑换为"全场无门槛电子抵扣券"，可在任意{{渠道范围}}使用 |
| 使用限制 | 无"满 XX 元可用"的门槛限制 |
| 差额处理 | 购买金额高于券面额 → 员工自付剩余部分；购买金额低于券面额 → 差额作废，不可提现（可补差价换购店内其他商品） |
| 叠加规则 | 不可与其他优惠券叠加使用 |

### 两个通道的核心区别

| 对比维度 | 通道 A（福利商城） | 通道 B（全场抵扣券） |
| --- | --- | --- |
| 员工需付现金 | 否 | 购买超面额商品时需补差价 |
| 可选商品范围 | 仅限指定福利款（约 {{SKU数量}} 款） | 全品类任意商品 |
| 券的面额价值 | 按成本价折算，实际感知价值较低 | 按券面额 100% 抵扣，感知价值高 |
| 公司实际成本 | 商品成本价（约为券面额的 40%-50%） | 券面额（但可拉动连带销售） |
| 推荐引导 | 适合不想花钱的员工 | 适合追求性价比、愿意升级消费的员工 |

**设计意图**：双通道设计解决了"员工想白嫖还是想升级"的选择困境，既照顾了不想多花钱的员工感受（通道 A），又引导有消费意愿的员工到店购物（通道 B），实现员工满意与公司引流双赢。
